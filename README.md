# ai-trash-loop-frontend

Dashboard for [AI Trash-Loop](https://github.com/ai-trash-loop): connect a repository, start an analysis, and browse
context-health findings with their evidence.

**Status: not started.** Planned stack: React, TypeScript, Vite, Tailwind, Recharts. Types will be generated from the
engine's report schema and the backend's OpenAPI spec. See [CLAUDE.md](CLAUDE.md) for conventions.
